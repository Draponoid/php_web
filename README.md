## Как запустить

### Требования
- PHP 8.x (встроенный сервер или XAMPP/OpenServer/Denwer)
- MySQL 5.7+ (только для ЛР В-1)

### Запуск через встроенный PHP-сервер
```bash
cd lab1
php -S localhost:8080
# открыть http://localhost:8080/page1.php
```

### ЛР В-1 (база данных)
1. Создайте базу данных, выполнив SQL из файла `lab9/db.php` (блок комментария в конце файла).
2. Настройте параметры подключения в `lab9/db.php`.
3. Запустите: `cd lab9 && php -S localhost:8080`.

## Краткое описание лабораторных работ

### ЛР А-1 — Основы PHP, статика → динамика
Трёхстраничный сайт. PHP выводит: дату в подвале, название страницы из переменной,
пункты меню через цикл, фотографию которая чередуется каждую секунду.

**Ключевые концепции:** `echo`, `date()`, переменные, условный оператор, цикл `foreach`.

### ЛР А-2 — Циклы и условия. Табулирование функции
Вычисляет кусочно-заданную функцию в цикле. Поддерживает 5 видов вёрстки результата
(текст, список `<ul>`, список `<ol>`, таблица, блоки `<div>`). Вычисляет max/min/среднее.

**Ключевые концепции:** `for`, `while`, `do-while`, `break`, `switch`, `round()`.

### ЛР А-3 — GET-параметры. Виртуальная клавиатура
Виртуальная цифровая клавиатура без хранилища на сервере — накопленная строка
передаётся через GET-параметр от клика к клику.

**Ключевые концепции:** `$_GET`, `isset()`, передача состояния через URL.

### ЛР А-4 — Пользовательские функции. Таблицы
Парсит строки формата `"C1*C2*C3#C4*C5*C6"` и строит HTML-таблицы.
Функции `getTR()` и `buildTable()` демонстрируют принцип повторного использования кода.

**Ключевые концепции:** `function`, `return`, `explode()`, `count()`.

### ЛР А-5 — Таблица умножения + два меню
Два меню (тип вёрстки и номер таблицы) работают независимо и сохраняют своё состояние.
Функции `outRow()` и `numLink()` строят таблицу умножения.

**Ключевые концепции:** вложенные `for`, передача нескольких GET-параметров,
`array_key_exists()`.

### ЛР А-6 — Формы. Математический тест
POST-форма с 6+ задачами. Программа автоматически решает задачу и сравнивает ответ.
Опционально отправляет результат по e-mail. Кнопка «Повторить тест» через GET.

**Ключевые концепции:** `$_POST`, `mail()`, `mt_rand()`, `str_replace()`.

### ЛР А-7 — Массивы. Алгоритмы сортировки
Динамическая форма (JavaScript добавляет поля). 5 алгоритмов сортировки + встроенная `sort()`.
На каждой итерации выводится состояние массива. Замер времени через `microtime()`.

**Ключевые концепции:** массивы, `sort()`/`rsort()`, `microtime()`, `exit()`.

### ЛР А-8 — Строки. Анализатор текста
Считает буквы, цифры, знаки препинания, слова, вхождения символов и слов.
Работает с русским и английским текстом через `mb_` функции.

**Ключевые концепции:** `mb_strlen()`, `mb_substr()`, `mb_strtolower()`, ассоциативные массивы, `ksort()`.

### ЛР В-1 — MySQL + модули. Записная книжка
Полноценное CRUD-приложение: просмотр (с пагинацией и сортировкой), добавление,
редактирование, удаление. Код разбит на модули (`menu.php`, `viewer.php`, `add.php`, `edit.php`, `delete.php`).

**Ключевые концепции:** `mysqli`, PDO, SQL (SELECT/INSERT/UPDATE/DELETE), LIMIT, `require`/`include`, prepared statements.
